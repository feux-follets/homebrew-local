# Evan Local

## How do I install these formulae?

`brew install evan/local/<formula>`

Or `brew tap evan/local` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "evan/local"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
